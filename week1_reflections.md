### Intro to Data Structures
Data structures are the "lifeblood of modern computing." They allow companies to understand their users and cater to them in a way that benefits both parties. They also allow devices to instantaneously communicate with each other. Ultimately, data structures offer a way to efficiently organize and store data.
### Types of Data Structures
Some data structures include records, arrays, linked lists, binary trees, hash tables, heaps, and graphs. Each have their own traits making them better for different purposes.
### Why Data Structures are Important
Data structures contribute to efficiency, versatility, and problem solving capabilities. Learning about multiple data structures is like being given a toolbox filled with various tools versus being handed a single tool. Knowing which one to use in a given situation can help save time, money, and computational resources.
